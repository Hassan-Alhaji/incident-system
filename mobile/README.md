# HSE Incident Reporter - تطبيق الجوال الميداني

تطبيق جوال خفيف وعصري مبني باستخدام **React Native (Expo)** مخصص حصرياً للموظف/المُبلّغ الميداني (`OC_REPORTER`).

---

## 📱 مميزات التطبيق

1. **تسجيل دخول آمن:**
   - الدخول الموحد بحساب الشركة **Microsoft SSO**.
   - خيار بديل برمز التحقق السريع عبر البريد الإلكتروني (**OTP**).
2. **رصد وتوثيق البلاغات الميدانية:**
   - **تحديد الموقع التلقائي (Auto GPS):** جلب إحداثيات المكان واسم الحي/الشارع تلقائياً بنقرة واحدة عبر `expo-location`.
   - **التصوير المباشر أو من المعرض:** التقاط صور للملاحظة/الحادث مباشرة عبر الكاميرا 📸 أو رفعها من ألبوم الصور 🖼️ مع معاينة فورية.
   - تصنيفات واضحة للبلاغ (ملاحظة، بيئة غير آمنة، تصرف غير آمن، حادث، وشيك، أمن، حريق).
   - رصد وجود إصابات بشرية.
3. **لوحة متابعة البلاغات (Dashboard):**
   - مطابقة لنظام الكمبيوتر للموظف:
     - 📥 **تحتاج ردي (Action Required):** تنبيه عاجل وتفاصيل ردود المراقب إن طُلب استيضاح، مع إمكانية الرد الفوري من الجوال.
     - ⏳ **قيد المعالجة (In Progress):** متابعة حالة وتطورات البلاغ.
     - ✅ **المغلقة (Closed):** أرشيف البلاغات المكتملة.
4. **شاشة تفاصيل البلاغ والخط الزمني (Status Stepper):**
   - مؤشر مرئي لمراحل المعالجة: استلام ➜ مراجعة ➜ جاري العمل ➜ إغلاق.

---

## 🚀 طريقة التشغيل والتجربة على الجوال

### الطريقة الأولى (الأسهل بنقرة واحدة):
- اضغط مرتين على ملف **`start_mobile.bat`** في المجلد الرئيسي للمشروع.

### الطريقة الثانية (عبر موجه الأوامر):
```bash
cd mobile
npm start
```

### 📲 التجربة المباشرة على هاتفك:
1. قم بتحميل تطبيق **[Expo Go](https://expo.dev/go)** مجاناً من متجر التطبيقات:
   - **آيفون (iOS):** افتح كاميرا الآيفون وامسح رمز الـ **QR Code** الظاهر في الشاشة.
   - **أندرويد (Android):** افتح تطبيق **Expo Go** واختر "Scan QR Code".
2. تأكد أن جوالك متصل بنفس شبكة الـ Wi-Fi مع جهاز الكمبيوتر (أو استخدم سحابة UAT الرسمية).
